The **FemCraft Client** is a Fabric-based client modpack focused on performance, usability, and expressive visual customization. It combines massive performance optimizations with a clean integration of the [Essential mod](https://modrinth.com/mod/essential) and a curated collection of high-quality utilities that players actually use in everyday gameplay.

Beyond performance, FemCraft introduces a wide range of visual upgrades: GLSL Shader Backgrounds, smooth animations, custom 3D models that bring previously flat elements to life, and a cohesive femboy & LGBTQ-themed aesthetic that gives the client a distinct identity. The interface is designed to be clear, modern, and highly customizable, making the overall experience more intuitive and thoughtfully structured than traditional competitors.

All-in-one, FemCraft aims to deliver a faster, cleaner, and more flexible Minecraft client without sacrificing style.

**IMPORTANT: ONLY RELEASE VERSIONS OF FEMCRAFT CONTAIN ALL FEATURES. BETA/ALPHA VERSIONS MISS ALL MODS THAT HAVE NOT YET UPDATED!**

## FAQ

### Why is there Meteor in the Modpack? Isnt that a Cheat Client?

This isnt Meteor, but Asteroid wich is a fork / distribution of the Meteor Client, a fabric based utility client mod. It has had most of Meteor's anarchy modules removed, in order to focus entirely on the utilities. The few modules remaining that could be considered cheats can only be used when the player is OP, or in singleplayer.

### Why do you use this versioning system (e.g. B1.12.4)?

The "**B**" stands for **Build**.  
- The **1** indicates this is the first major version (V1) of the FemCraft Client.  
- The **12** refers to the Minecraft version (1.12).  
- The **4** represents the **4th build** for that specific Minecraft version.

"Build" here does **not** refer to compiling a JAR file. It means a manually assembled and tested version of the entire modpack (mod selection, configurations, optimizations, and tweaks). Each new build is an improved iteration.

### Why doesn't the latest version look like the screenshots? Why are some features missing?

Because many versions are **Beta or Alpha builds**. These versions automatically exclude all mods that have not yet been updated to the current Minecraft version.

**Only the final Release versions** contain the complete feature set. Always check the version label and changelog before expecting everything shown in the showcase videos.

### Feature XYZ annoys me / A mod or feature is missing!

FemCraft is a **modpack** — you have full control. You can:
- Enable or disable almost any mod
- Change settings
- Swap resource packs and shaders

If something is missing or bothering you, feel free to open a ticket on our **Discord** and suggest the mod or feature. We review reasonable suggestions and consider adding them to future builds.
